# byteutils

[![PyPI version](https://badge.fury.io/py/byteutils.svg)](https://badge.fury.io/py/byteutils)
[![Python Versions](https://img.shields.io/pypi/pyversions/byteutils.svg)](https://pypi.org/project/byteutils/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Универсальная библиотека для работы с единицами измерения памяти на Python.

## ✨ Возможности

- ✅ Поддержка десятичных единиц (KB, MB, GB, TB, PB, EB, ZB, YB)
- ✅ Поддержка двоичных единиц (KiB, MiB, GiB, TiB, PiB, EiB, ZiB, YiB)
- ✅ Шуточные единицы (IPY, HPY, GPY, JPY) для гигантских объёмов
- ✅ Конвертация между любыми единицами
- ✅ Форматирование в человекочитаемый вид
- ✅ Парсинг строк (поддерживает русские названия)
- ✅ Автоматический выбор оптимальной единицы
- ✅ CLI-интерфейс
- ✅ Высокая точность (Decimal)
